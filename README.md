# Klipper, uma edição SyncServ

Agendamento pelo WhatsApp e gestão (agenda, comanda e caixa) para barbearias com 1 a 5 profissionais. O SyncServ é a
plataforma; o Klipper é a edição para barbearias. **Projeto autoral em fase de piloto**, desenvolvido por Matheus Souza:
serve como portfólio e está aberto a barbearias interessadas em testar.

**Site:** https://souzza-matheus.github.io/klipper-site/ · **Detalhes técnicos:** https://souzza-matheus.github.io/klipper-site/como-foi-feito.html
